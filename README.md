# Современные технологии в программировании (учебный проект) 

Разработка мобильного приложения "FitTracker" на платформе Android.

## 🛠 Стек технологий

Для реализации был выбран современный стек технологий:

- **Kotlin** — язык разработки
- **Jetpack Compose** — фреймворк для реализации UI составляющей приложения
- **Room** — локальная БД на основе SQLite
- **MVVM + Repository** — архитектура
- **Coroutines + Flow** — асинхронность
- **Navigation Compose** — навигация
- **MPAndroidChart** — визуализация прогресса
- **Android Studio** - IDE
- **Git + GitHub** - VCS

## ✨ Описание проекта

FitTracker - мобильное приложение для отслеживания прогресса в силовых тренировках.

Позволяет:

- Создать программу тренировки на определенный день (например, вторник: "День спины и плеч" -> список упражнений с описанием)
- Добавлять в Базу упражнения на свой интерес с кастомными параметрами пользователя (например: "Вес", "Кол-во повторов", "Кол-во подходов")
- Фиксировать результаты каждой тренировки
- Хранить историю всех выполненных тренировок для анализа
- Отслеживать прогресс по каждому упражнению через графики
- Полный CRUD: создание, просмотр, редактирование и удаление отдельных тренировок и упражнений

Данные будут храниться локально на устройстве, поэтому интернет не потребуется.
