# Современные технологии в программировании (учебный проект) 

Разработка мобильного приложения "Фитнес-трекер" на платформе Android.

## 🛠 Стек технологий

Для реализации был выбран современный стек технологий:

- **Kotlin** — язык разработки
- **Jetpack Compose** — фреймворк для реализации UI составляющей приложения
- **Room** — локальная БД на основе SQLite
- **MVVM + Repository** — архитектура
- **Coroutines + Flow** — асинхронность
- **Navigation Compose** — навигация
- **MPAndroidChart** — визуализация прогресса
- **Android Studio** - IDE
- **Git + GitHub** - VCS
